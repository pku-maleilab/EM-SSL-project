Release Notes

0.3.0

  • Foundation-model core. The model lives in the published omniem package (EM-DINO ViT-L backbone); the plugin is a thin, parity-verified bridge around it.
  • Custom tasks and models. Add your own Image-to-Image and Image-to-Label tasks through Preferences (⚙️) and import fine-tuned OmniEM checkpoints (full or head-only).
  • Shared backbone + per-task heads. Weights are stored as one shared ViT-L backbone plus small per-task head files; full checkpoints are split automatically on import, and a backbone-management panel lets you inspect, rename, add, and remove backbones.
  • Multi-GPU sliding-window inference with pre-inference GPU-memory estimates and out-of-memory-safe execution.
  • Full Volume mode, expanded. The single-pass, seam-free mode introduced in 0.2.0 now covers both task types and integrates the pre-inference memory estimates.
  • On-disk (large-volume) inference that streams to disk with bounded RAM.
  • Image-to-Image post-processing: rescale model output to the input's intensity range.
  • GUI improvements: reorganized Preferences and Tools dialogs, a single resize Scale (×) control for Image-to-Image output, and friendlier window sizing.

0.2.0

  • Full Volume inference: single-pass, tile-artifact-free mode for in-memory data.
  • Post-processing tools (🧰) with intensity rescaling.
  • Logging to ~/.napari-omniem/napari_omniem.log and a View Logs button.
  • Config-schema validation, atomic config writes, and tooltips throughout.

0.1.0

Initial release.

  • In-memory and on-disk (large-volume) inference.
  • Sliding-window tiled inference built on MONAI.
  • OmniEM model with the EMDINOv1-ViT-L backbone.
  • Built-in tasks: denoising, super-resolution, mitochondria segmentation.
  • napari contributions: widget, .tif/.tiff reader, .npy writer, and EM sample data.
